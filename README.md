
# STOREFINAL

Chatbot para E-commerce con Express, MySQL y Azure OpenAI.

## Integrantes
- Sandro: Chatbot, Azure OpenAI y frontend.
- Félix: Backend, MySQL y API de productos.

## Ramas
- main: Proyecto integrado.
- feature/chatbot: Sandro.
- feature/backend: Félix.

## Instalación
1. Ejecutar `npm install`.
2. Copiar `.env.example` a `.env`.
3. Configurar las variables de entorno.
4. Ejecutar `npm run dev`.
